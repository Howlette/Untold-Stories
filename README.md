# Untold Stories and Unsung Heroes

Story submission website for the limited series "Untold Stories and Unsung Heroes," a limited series of stories based on true events.

## Sites

- Review site: https://dev.limitedseries.net (not indexed by search engines)
- Future public site: https://untoldunsung.com

## Hosting

Static site served by Cloudflare Pages. No build step: the site is `index.html` at the repository root.

## Status

- Submissions are not open. The form validates entries but sends nothing.
- The submission terms are a draft pending review by legal counsel. Bracketed items are for counsel to complete.
